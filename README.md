# Gedik Örme website

Bilingual (TR/EN) B2B site for a knitted-fabric manufacturer. Spec: `docs/plan.md`. Work tracking: `tasks.md`, `decisions.md`. Deployment: `DEPLOYMENT.md`.

```sh
npm install
npm run dev:vinext     # http://localhost:3001
npm run check          # lint, typecheck, tests, build
```
